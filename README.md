# Balloon Mini Game — Cosmic Popper

**Cosmic Balloon Pop** — a fun browser-based arcade game where you pop colorful balloons in space!

### 🎮 How to Play
- **Point your mouse** at any balloon
- **Click** with the left mouse button (or tap on mobile)
- Popped balloons give points and beautiful explosion animations
- You have **3 lives** — miss too many times and you're out!
- Difficulty increases over time (more balloons appear)

### ✨ Features
- Fully client-side (runs in any browser, no server needed)
- Works great on mobile devices (touch support)
- Pure HTML + CSS + TypeScript (clean and lightweight)
- Just open `index.html` and play!

### 📥 How to Run
1. Clone the repo or download the files
2. Open the `index.html` file in your browser
3. Start popping balloons!
